SongBox

Applied audio-ML pipeline for karaoke · Aug – Sep 2026

Upload a song and get a synced karaoke track: Demucs separates the stems, Whisper transcribes the vocals, wav2vec2 aligns every word and CREPE tracks pitch. A rights gate fingerprints each upload before any of it reaches a GPU.

  • 68.2 ms median word-alignment error on English tracks, measured with a dedicated evaluator. The ±50 ms target isn't met yet, and the repo says so.
  • FastAPI and PostgreSQL backend with row-level-security multi-tenancy, Argon2id session auth and a swappable local or Modal GPU backend. CI runs ruff, strict mypy, migrations and pytest.

Python · FastAPI · PyTorch · PostgreSQL · Redis · Next.js · Docker

Code for SongBox Alignment evaluator Status and known gaps

TaxShoeBox

Full-stack tax-document organizer

Capture receipts, income and deductions, attach files, and see yearly totals. A React front end on a Supabase (PostgreSQL) backend, with a one-click demo mode that runs in the browser on sample data.

  • FORCE row-level security on every table, so a user can only touch rows where auth.uid() = user_id. The anon role is revoked, and database CHECK constraints back the app's own validation.
  • Dashboard totals are computed in Postgres by a get_tax_summary function, with composite indexes that lead with user_id to match the security predicate.

React · Vite · Supabase · PostgreSQL · Tailwind CSS

Code for TaxShoeBox Schema and RLS policies Security write-up
