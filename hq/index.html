Connect Canvas

Canvas doesn’t let other websites read its data directly, so HQ connects one of two ways. Either way your data stays in this browser.

1. Sync button Recommended · no setup

  1. Show your bookmarks bar (Ctrl/⌘ + Shift + B).
  2. Drag this button onto it: ⟳ Sync to HQ
  3. Open UTD’s Canvas (eLearning), log in, and click the bookmark on any Canvas page.

It reads your planner, grades and assignment weights using the login you already have (no password or token), then opens HQ with the data. Click it again whenever you want fresh data.

For phones: bookmark any page, edit the bookmark, and paste this as its address.

2. Access token Auto-syncs every time you open HQ

Needs a Canvas access token (Canvas → Account → Settings → New access token) and a small free proxy you deploy once, because Canvas blocks direct requests from other sites. Setup steps: hq/README.md.
